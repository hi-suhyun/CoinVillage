# 업비트 정원(Upbit Garden) 앱 설계 문서

작성일: 2026-06-28
대상: 금융 + 게임 결합형 업비트 게이미피케이션 앱 (최종 기획서 반영)

## 0. 확정된 제약 및 결정

메모리 기반 고정 제약(절대 변경 금지):

- **플랫폼:** Expo SDK 54 (스토어 Expo Go 호환), 업그레이드 금지.
- **언어:** JavaScript 전용 (TypeScript 금지).
- **거래 정책:** 실제 주문 API 호출 절대 금지. 모든 매매는 로컬 가상지갑 시뮬레이션.
- **언어/UX:** 한국어 UI.

브레인스토밍에서 확정한 결정:

1. **시세 데이터:** 업비트 공개 시세 API(`/v1/ticker`, 무인증·읽기 전용) 사용, 네트워크 실패 시 목업 폴백.
2. **내비게이션/저장:** expo-router(파일 기반) + AsyncStorage.
3. **정밀도 라이브러리:** decimal.js.
4. **가상자금 시드:** 온보딩 "초기 투자 한도"(최대 500만원)가 곧 가상지갑의 초기 가용현금.
5. **김프/역프:** 외부 환율/해외시세 미연동. 시장 전체 평균 변동률 + `KRW-USDT` 프리미엄 부호로 근사.

### 상태 관리

- Context API 2개(Auth, Wallet). 외부 상태 라이브러리 없이 Expo Go 호환 유지.
- 모든 영속 데이터는 AsyncStorage(`src/store/storage.js` 래퍼 경유).

### 데이터 소스

- 업비트 공개 시세 API `GET https://api.upbit.com/v1/ticker?markets=...` (무인증).
- 마켓: `KRW-DOGE, KRW-MEW, KRW-SHIB, KRW-PEPE, KRW-BONK, KRW-PENGU` + 김프 근사용 `KRW-USDT`.
- 폴링 주기 약 5초. 네트워크 실패/타임아웃 시: 마지막 캐시값 → 없으면 목업 가격. "오프라인 시세" 배지 표시.
- **주문 API는 절대 호출하지 않음.** 모든 매매는 WalletContext 내 가상 체결.

## 2. 인증 & 가상지갑 데이터 모델

### 인증 (AuthContext + AsyncStorage)

- 저장 키 `auth`: `{ apiKey, secretKey?, passwordHash, investLimit, createdAt }`
  - 비밀번호(4~6자리)는 평문 저장 금지 → expo-crypto SHA-256 해시로 저장. 매매 더블체크 시 입력값 해시 비교.
  - API Key는 "연동" UX용 로컬 저장만. 주문에 사용하지 않음(시세는 무인증).
- 저장 키 `session`: `{ loggedIn: true }`. 로그인 시 set, 로그아웃 시 제거.
- **인증 게이트(`app/index.js`):** 부팅 시 `auth`·`session` 읽어 분기.
  - `auth` 없음 → 온보딩(login)
  - `auth` 있고 `session` 없음 → 로그인(login)
  - 둘 다 있음 → 메인(garden)
  - 앱 완전 종료 후 재실행해도 `session`이 없으면 로그인으로 강제.
- **가드레일:** 온보딩 투자 한도 입력은 `min(입력값, 5,000,000)`으로 강제 클램프 + UI 경고.

### 가상지갑 (WalletContext + AsyncStorage)

저장 키 `wallet`:

```js
{
  cashKRW: "5000000",            // Decimal 문자열, seed = investLimit
  initialLimit: "5000000",       // 한도 사용률 계산 기준
  holdings: {
    "KRW-DOGE": { qty: "1234.56789012", avgBuy: "180.5" },
  },
  trades: [ { market, side, qty, price, amount, ts } ]  // 체결 이력
}
```

- 모든 수량·금액은 **문자열로 저장하고 decimal.js로만 연산**(부동소수점 왜곡 차단).
- **한도 사용률** = (initialLimit − cashKRW) / initialLimit.
- **총자산** = cashKRW + Σ(holding.qty × 현재가). **가용현금** = cashKRW.

### 파생 지표(정원/날씨용) — `src/utils/market.js` 순수함수

- 코인별 `signed_change_rate`(업비트 ticker 24h 변동률) 사용.
- **표준화 위치값:** 변동률을 `[-maxAbs, +maxAbs]` 클램프 후 `[0,1]` 정규화 → 캐릭터 X좌표. 0.5=중앙, >0.5 우측(상승), <0.5 좌측(하락).
- **장 분위기:** 6종 평균 변동률 부호(양수=맑음, 음수=흐림).
- **김프 근사:** `KRW-USDT` 변동률/프리미엄 부호(양수=쨍쨍, 음수=비).

## 3. Page 2 — 메인 화면 "나의 정원"

레이아웃 시선 흐름: 상단 대시보드 → 중앙 정원 → 하단 제어.

- 상단 탭바: `[정원] [자산] [상점]` + 우상단 `[로그아웃]`. **지도 아이콘/route 완전 제거.**
- 정원 컨테이너 좌상단 `[← 하락]`, 우상단 `[상승 →]` 독립 가이드 블록(항상 노출).

핵심 메커니즘:

- **캐릭터 spawn:** `holdings`에 qty>0인 코인만 렌더. 매수 체결 즉시 등장, 매도로 0이면 제거.
- **X좌표 = 표준화 변동률:** `left = trackPadding + normalized(rate) × (trackWidth − charWidth)`. `Animated.timing`으로 좌우 전진/후진(둥둥 뜨는 wobble 금지).
- **Y좌표 레일 밀착:** 트랙 상단 경계 Y 상수 기준으로 캐릭터 발이 레일에 닿도록 `bottom` 고정(떠다님 금지).

날씨 시스템:

- 평균 변동률 ≥ 0 → 밝은 배경 + **해만** 렌더. < 0 → 어두운 배경 + **먹구름만** 렌더(해 완전 제거, 상호 배타).
- 김프 근사 양수 → 쨍쨍(빛 효과), 음수 → 비 파티클 오버레이.
- **해 클릭:** 해 아래쪽 팝업(우상단 가이드 비가림) → `[YYYY.MM.DD.HH:MM] / "장이 좋습니다"`.
- **먹구름 클릭:** 먹구름 위쪽 팝업 → `[YYYY.MM.DD.HH:MM] / "장이 좋지 않습니다"`.

정원 이벤트:

- 소액 거래 발생 → 바닥 아기 고양이떼 소풍 애니메이션(일정 시간 후 소멸).
- 고래(대형) 거래 발생 → 하늘 풍선 고래가 가로질러 지나가며 선물 낙하, 클릭 시 고래 안내 팝업.
- 임계값(소액 < 5만원, 고래 ≥ 100만원 등)은 `src/data/coins.js` 상수로 분리.

**이모지 전면 금지:** 모든 시각 요소는 픽셀아트 스프라이트/벡터로 그림. UI 텍스트·요소에 이모지 미사용.

## 4. Page 3 — 자산/포트폴리오

- 우상단 `[로그아웃]` 동일 배치.
- **블록 ①:** 투자 한도 + 한도 사용률 바를 한 블록에 통합.
- **블록 ②:** 가용현금 + 총자산 한 블록 통합. 가용현금=작게 위, 총자산=볼드 강조 아래.
- **블록 ③:** 보유 코인 비중 시각화(도넛 또는 스택바, 현금 포함).
- 총자산은 실시간 시세 평가금액 합산.

## 5. Page 4 — 코인 상점(매수/매도)

- 6종 세로 리스트: 스프라이트, 한글명+닉네임, 현재가, 변동률, `[매수] [매도]`.
- 우상단 `[로그아웃]` 동일 배치.
- **코인 용어 한 줄 사전:** 용어 버튼 클릭 시 Thinking Box 형태 툴팁, 설명은 정확히 한 문장.

### 매매 프로세스(모달)

1. `[매수]/[매도]` → 모달: 한국어 실제 이름(예: "도지코인"), 수량 입력, 총 금액(실시간 계산), 비밀번호 입력칸.
2. 수량 입력은 **decimal.js로만 파싱/계산**. `0.0001` 입력 시 `0.00008969...` 왜곡 발생 금지. 표시 자릿수는 마켓별 고정(절사).
3. **전량 매도 버튼:** 보유 수량을 Decimal 그대로 채워 미소수량 잔존 없이 0 청산.
4. 비밀번호 해시 일치해야 체결. 불일치 거부.
5. 체결:
   - 매수 → `cashKRW -= amount`, `holdings[m].qty += qty`(가중평균 단가 갱신). 가용현금 초과 매수 차단.
   - 매도 → `holdings[m].qty -= qty`, `cashKRW += amount`. qty가 0이면 키 제거. 메인 정원 캐릭터 즉시 동기화.
6. 체결 직후 정원 이벤트(소액=고양이/고래=풍선고래) 트리거 연동.

### 정밀도 보정 핵심 규칙

- 저장·연산: 전부 문자열 + `Decimal`. 표시: `toFixed(자릿수, ROUND_DOWN)`.
- 매도 수량과 보유량 비교는 `Decimal.cmp`로 판정(부동소수점 `>=` 금지) → 잔량 매도 불가 버그 해소.

## 6. 에셋 처리

- `img/`의 6종 캐릭터 png를 `assets/characters/`로 복사·매핑:
  - `doge.png`(=`_01`), `mew.png`(=`_02`), `shib.png`(=`_05`), `pepe.png`(=`_04`), `bonk.png`(=base 야구방망이 시바), `pengu.png`(=`_03`).
  - 상점 아이콘 `shop`(=`_283`). **MAP 아이콘/route 미사용·제거.**
- **누끼(배경 제거):** 원본 흰 배경을 투명 PNG로 가공(빌드 전 1회). 노란 업비트 박스 전면 파란 U 로고는 축소돼도 또렷하도록 원본 해상도 유지 + `resizeMode="contain"`.

## 7. 디자인 토큰 (`src/theme/index.js`)

- 폰트: **Pretendard**(expo-font 로드), 전 텍스트 적용. 이모지 폰트 미사용.
- 색상: 동물의 숲풍 파스텔(잔디 그린, 하늘 블루) + 픽셀아트 레트로 액센트(레일 브라운, 업비트 블루 `#093687`).
- 픽셀 느낌: 스프라이트는 pixelated, UI 카드/버튼은 가독성 우선 현대 고딕 톤.

## 8. 에러 처리

- 시세 API 실패/타임아웃 → 마지막 캐시값 → 없으면 목업 가격, "오프라인 시세" 배지. 앱 계속 동작.
- AsyncStorage 손상/스키마 불일치 → 안전 기본값 마이그레이션. 지갑 초기화는 사용자 확인 후.
- 매매 검증: 잔액/보유 초과, 비번 불일치, 수량 0/음수 → 모달 인라인 에러, 체결 차단.
- 한도 가드레일: 500만원 초과 입력 클램프.

## 9. 테스트 & 검증

- **순수 로직 단위 테스트(jest):** decimal 매매 계산(0.0001 왜곡 없음·전량매도 잔량 0), 표준화 변동률→X좌표, 한도 사용률, 비번 해시, 한도 클램프, 장분위기/김프 부호 판정. UI 무관 순수 함수로 분리.
- **수동 검증 체크리스트:** Expo Go 부팅, 로그인 게이트(재실행 시 로그인으로), 매수→캐릭터 spawn, 매도→동기화, 날씨 전환·팝업, 로그아웃 리다이렉트.
- 메모리 제약 준수 확인: 주문 API 미호출, TypeScript 미사용, SDK 54 고정.
