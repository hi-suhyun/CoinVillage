# 세로형 픽셀 게임 UI 리디자인 설계 문서

작성일: 2026-07-08
대상: 기존 Upbit Garden 앱의 전체 UI 스타일을 세로(portrait) 폰 기준 + 레트로 픽셀 게임 감성으로 리디자인

## 0. 확정된 제약 및 결정

메모리 기반 고정 제약(절대 변경 금지):

- **플랫폼:** Expo SDK 54 (스토어 Expo Go 호환), 업그레이드 금지.
- **언어:** JavaScript 전용 (TypeScript 금지).
- **거래 정책:** 실제 주문 API 호출 절대 금지. 모든 매매는 로컬 가상지갑 시뮬레이션.
- **언어/UX:** 한국어 UI.

이번 리디자인에서 확정한 결정:

1. **스타일 방향:** 레트로 픽셀 게임 감성 강화(기존 픽셀아트 자산을 더 밀어붙임).
2. **폰트 정책:** 타이틀·탭라벨·HUD·라벨·등락률 = 한글 픽셀 폰트. 긴 본문·입력창·큰 금액 숫자 = Pretendard 유지.
3. **기준 방향:** 세로 폰(폭 360~430dp). 주 내비는 하단 탭바, 조작은 하단, 읽기전용 정보는 상단.
4. **정원 레일:** 가로 → **세로 레일**. 등락률을 위(상승)/아래(하락)로 매핑.
5. **겹침 금지:** 레일 위 스프라이트는 서로 겹치지 않는다(레인 분할 + 크기 제약으로 구조적 차단).
6. **범위:** 전 4화면(로그인/정원/자산/상점) + 공통 컴포넌트. 거래·지갑·인증·시세 로직은 변경 없음(스타일/레이아웃만).

## 1. 비주얼 시스템 — 픽셀 게임 강화

### 폰트

- **픽셀 폰트(신규 에셋):** 한글 지원 무료 비트맵 폰트(둥근모꼴/갈무리 계열 중 라이선스 확인 후 1종 선정). `assets/fonts/`에 추가하고 `app/_layout.js`의 `useFonts`에 등록.
  - 적용 대상: 화면 제목, 탭 라벨, 정원 HUD(시장 평균/김프), 방향 가이드, 코인 닉네임/등락률, 카드 라벨·퍼센트.
- **Pretendard(기존 유지):** 긴 안내문(GlossaryBar, 정원 하단 설명), 입력창 텍스트, 큰 금액 숫자(총자산/가용현금), 오류 메시지.
- 판독성 원칙: 작은 크기의 긴 한글/정밀 숫자는 픽셀 폰트를 쓰지 않는다.

### 프레임 & 형태

- 카드·모달·버튼: 2~3px 하드 픽셀 테두리 + 각진 오프셋 그림자(블러 없음). 둥근 모서리 대신 각진(또는 1px 계단) 코너.
- 공통 픽셀 프레임 컴포넌트 `PixelFrame` 1종 신규(테두리+오프셋 그림자 캡슐화). 카드/버튼/모달이 재사용.
- 버튼은 눌림(press) 상태에서 그림자 오프셋이 사라지며 살짝 내려앉는 픽셀 버튼 피드백.

### 컬러

- 기존 `theme.colors` 토큰을 유지하되 채도를 올린 8bit 팔레트로 튜닝.
- 상승=빨강(`up`), 하락=파랑(`down`) 한국 관례 유지.
- 도트 배경 타일(잔디/하늘)용 색 토큰 추가.

## 2. 세로 레이아웃 시스템

- **하단 탭바 = 주 내비**(정원·자산·상점). 상단 헤더는 화면 제목 + 로그아웃만.
- 조작(매수/매도/확인) = 하단 바텀시트(`TradeModal` 기존 구조 유지). 읽기전용 정보 = 상단.
- 모든 화면은 세로 스크롤 기준. 가로 그리드/가로 넓은 씬 금지.

## 3. 정원 화면 (핵심) — 세로 레일

### 레일 개념

- 씬을 세로로 길게(대략 3:4 이상, 화면 폭 기반 높이 산출).
- **세로축 = 등락률.** 위쪽 하늘 = 상승(+), 아래쪽 땅 = 하락(−), 가운데 기준선 = 0%.
- 각 보유 코인은 자기 레인(칼럼)의 넝쿨/기둥 위에 떠 있고, 등락률만큼 위/아래에 위치하며 미세하게 bobbing 애니메이션.
- 방향 가이드(`GuideBlocks`)는 세로로 회전: 상단 `↑ 상승`, 하단 `↓ 하락`.
- 상단 HUD: `시장 평균`, `김프` 2개만 고정. 날씨(해/구름/비)는 상단 유지.

### 겹침 방지 규칙 (필수)

- **가로 = 레인, 세로 = 등락률.** 보유 코인은 폭을 균등 분할한 고정 레인에 각각 배치. 같은 레인 안에서만 상하로 이동하므로 이웃 침범 불가.
- **레인 폭에 맞춘 스프라이트 크기 제한:** `laneWidth = sceneW / N`, `spriteSize = min(기본크기, laneWidth − gap)`. 보유 코인이 늘면 스프라이트가 자동 축소되어 겹치지 않음.
- **상한:** 코인은 총 6종(`COINS`)이라 레인 최대 6개. 360dp 기준 레인당 ~56dp, 스프라이트 ~44dp + gap로 안정.
- **레인 순서 고정:** `COINS` 정의 순서(도지→퍼지펭귄)로 항상 같은 x 위치 → 값이 바뀌어도 좌우로 튀지 않고 상하로만 이동.
- **세로 클램프:** 최상단(+)·최하단(−)에서도 스프라이트가 프레임/HUD/땅을 뚫지 않도록 `pad`로 클램프.
- 결과: **가로 겹침**은 레인 분할로, **세로 겹침**은 레인당 1개로 원천 차단.

### 이벤트 연출

- `CatPicnic`/`BalloonWhale` 유지. 세로 씬 좌표에 맞게 위치만 조정.

## 4. 상점 화면

- 3열 그리드 → **1열 풀폭 픽셀 카드 행**. 좌: 픽셀 코인 아이콘 + 이름(픽셀) + 현재가(Pretendard). 우: 등락률(픽셀) + 매수/매도 픽셀 버튼.
- 오프라인 배지·`GlossaryBar` 픽셀 스타일 적용(안내 본문은 Pretendard 유지).

## 5. 자산 화면

- 카드 3블록(한도/총자산/보유비중) 구조 유지, `PixelFrame` 적용.
- 라벨·퍼센트 = 픽셀, 큰 금액 = Pretendard. 보유비중 바는 픽셀 세그먼트로.

## 6. 로그인/가입 화면

- 픽셀 프레임 입력창·버튼, 픽셀 타이틀 로고. 가입/로그인 흐름·로직·검증은 그대로.

## 7. 코드 영향 범위

- `src/theme/index.js`: 토큰 확장(픽셀 폰트 패밀리, 테두리 두께, 오프셋 그림자, 8bit 팔레트, 도트 배경색). 대부분 스타일 변경이 여기로 수렴.
- `assets/fonts/`: 한글 픽셀 폰트 에셋 추가. `app/_layout.js` `useFonts` 등록.
- `src/utils/market.js`: `charX` → `charY`(등락률→세로 위치, 방향 반전) + 레인 x 분배 헬퍼 `laneX(index, count, sceneW)` + 스프라이트 크기 산출 헬퍼. 순수함수라 단위 테스트 갱신/추가.
- `src/components/Character.js`, `app/(tabs)/garden.js`, `src/components/GuideBlocks.js`: 세로 레일 배치로 수정.
- `src/components/PixelFrame.js`: 신규(카드/버튼/모달 공통 픽셀 테두리+그림자).
- `src/components/CoinRow.js`, `TradeModal.js`, `RatioBar.js`, `GlossaryBar.js`, `LogoutButton.js`, `PrimaryButton.js`, `assets.js`, `shop.js`, `login.js`: 픽셀 스타일 적용(스타일/레이아웃만).

## 8. 테스트/검증

- `__tests__/market.test.js`: `charY` 방향(양수 rate → 작은 y, 음수 rate → 큰 y), `laneX` 균등 분배, 스프라이트 크기 상한을 검증. **레인 분할 시 두 스프라이트의 x 범위가 겹치지 않음**을 명시적으로 테스트.
- 기존 wallet/decimal/auth/upbit 테스트는 로직 무변경이므로 그대로 통과해야 함.
- 시각 검증: 세로 폰 기준으로 6종 전부 보유 시 겹침이 없는지, 극단 등락률(±20% 이상)에서 클램프가 동작하는지 실기기/시뮬레이터 확인.

## 9. 범위 밖(그대로 유지)

- 거래 로직, 가상지갑 데이터 구조, 인증/세션, 시세 폴링, 데이터 소스, 임계값 상수.
- 신규 기능 추가 없음. 스타일·레이아웃·정원 레일 방향/배치만 변경.
